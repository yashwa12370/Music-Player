🎧 WaveTune — Music Player

WaveTune is a modern, responsive web-based music player built with HTML, CSS, and JavaScript. It provides a smooth and interactive music experience with online music streaming, search, favorites, recently played songs, and customizable themes.

✨ Features

🎵 Online music search & streaming

❤️ Favorites & Recently Played

▶️ Play, Pause, Next & Previous

🔀 Shuffle, Repeat & Autoplay

🔊 Volume & Progress Controls

🌙 Dark / Light Mode

📱 Responsive design

👤 Interactive profile menu

🎨 Modern Spotify-inspired interface

🛠️ Tech Stack

HTML5 • CSS3 • JavaScript • Audius API • LocalStorage

🚀 Purpose

Built as a practical web development project to strengthen skills in JavaScript, API integration, DOM manipulation, responsive UI design, and browser storage.

WaveTune — Discover. Play. Enjoy. 🎶
